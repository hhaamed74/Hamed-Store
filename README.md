# 🛒 Hamed Store | Premium Shop

موقع تجارة إلكترونية متكامل (Full-Stack) يتيح للمستخدمين استعراض المنتجات وطلبها، مع لوحة تحكم كاملة للمدير (Admin).

## 🚀 التقنيات المستخدمة

- **Frontend:** HTML5, CSS3 (Custom Design), JavaScript (Vanilla).
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB Atlas (Cloud).
- **Security:** JWT (JSON Web Tokens) & Bcrypt.

## 🛠️ المميزات

- [x] نظام تسجيل دخول وتسجيل حساب جديد.
- [x] لوحة تحكم للأدمن (Dashboard) لإضافة المنتجات.
- [x] عرض المنتجات بشكل دايناميك من الداتابيز.
- [x] حماية المسارات (Protected Routes) بحيث لا يدخل للأدمن إلا المصرح لهم.

## ⚙️ طريقة التشغيل (Locally)

1. قم بتحميل المشروع (Clone).
2. افتح الـ Terminal في فولدر الـ Backend ونفذ `npm install`.
3. قم بإنشاء ملف `.env` ووضع الـ `MONGO_URI` الخاصة بك.
4. ابدأ السيرفر باستخدام `npm start`.
